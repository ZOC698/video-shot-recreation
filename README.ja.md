# 映像カット分析と再現 · Video Shot Recreation (v2.0)

[中文](README.md) | [日本語](README.ja.md) | [English](README.en.md)

監督訓戒、**Codex 風コンタクトシート（10〜100+フレーム適応型）**、**1カット1組の精密コマ送り分析**、**6次元映像解体** を統合した産業級映像分析・絵コンテ移植スキル。

---

## v2.0 の主要進化点

1. **カメラワーク意識と画角展開**：単調な固定カメラを排除し、ダイナミックなカット割りを徹底。
2. **Codex 組図と6次元分析**：コンタクトシート形式と6次元（レンズ、視覚効果、物語、力学、心理、技法）分析の義務化。
3. **疎なコマ抜きと妄想の完全排除**：重要アクションを0.1秒単位で高密度分析。
4. **1カット1組とVFX多段階形態追跡**：衝撃波の三態変化（引力アーチ→渦流→半球ドーム）を全フレーム追跡。
5. **情報密度適応型サンプリング（上限なし原則）**：情報量に応じて最大100+フレームまで自適応展開。

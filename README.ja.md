# 映像のショット分析と再現 · Video Shot Recreation

[中文](README.md) | [日本語](README.ja.md) | [English](README.en.md)

参考映像の分析、動作の定量化、キャラクターの置き換え、プロンプト作成、生成結果の比較を行う Codex Skill です。中国語・日本語・英語の文書を用意しています。通常はユーザーの言語で回答し、プロンプトの言語指定があればそれに従います。

「この構図を残して自分のキャラクターに置き換えたい」「今回の動きがおかしい理由を知りたい」といった依頼に対応します。特定の動画モデルに依存せず、利用前に検証事例を提出する必要もありません。Markdown のみで構成され、スクリプト、生成サービス、映像素材は同梱していません。

## できること

- ショット単位・フレーム単位で構図、動作、カメラ、エフェクト、物語上の役割を分析。
- 敵の数、同時攻撃者数、射撃の波、間隔、動作時間、移動量を定量化。
- 指定されたショットを残し、人物、衣装、舞台を参考素材に置き換え。
- 原映像と生成版を比較し、見える差異、指示不足、原因の仮説を区別。
- 完全なプロンプト、簡単な位置関係図の説明、編集案を依頼に応じて作成。

**定量化と因果関係を併用し、ユーザーの目的を優先します。** 数値を避ける必要はありません。コミュニティの経験則はモデルの必須パラメーターではなく、人物の置き換えを勝手な物語変更に拡大しません。

## 依頼例

```text
$video-shot-recreation を使い、この動画の5〜12秒を分析してください。
離陸から命中までをコマ送りで確認し、画像と説明を対応させてください。
聞いていない音は推測しないでください。
```

```text
参考映像の主要構図、ショット順、衝突して入口に入る結末を残してください。
主人公を私のキャラクター画像に置き換え、30秒の完全なプロンプトにしてください。
画面内の敵、同時攻撃者、一斉射ごとのパルス数を別々に定量化してください。
```

```text
原映像、第1版、第2版を同じ動作イベントで対応づけて比較してください。
第2版が走る動作になった理由と、最後の衝突が押し合いに見える理由を重点的に。
診断と部分的な修正案だけを出し、全体は書き直さないでください。
```

これらは呼び出し例であり、生成成功を検証済みの事例ではありません。

## インストール

Codex のスキルディレクトリ内の `video-shot-recreation` フォルダーに本リポジトリを配置します。既定は `~/.codex/skills`、`CODEX_HOME` を設定している場合はその配下の `skills` です。既定設定での例：

```sh
git clone https://github.com/ZOC698/video-shot-recreation.git ~/.codex/skills/video-shot-recreation
```

同名フォルダーがある場合は上書きせず、差分とローカル変更を先に確認してください。インストール後は新しい会話で `$video-shot-recreation` を呼び出します。認識されない場合は会話を開き直してください。インストールせず Markdown を読むだけでも利用できます。

## 設計の背景

実際の共同制作で問題になったのは「迫力」「超高速」といった形容詞の不足だけではありません。

- 新しい動画に前の作品の設定を持ち込む。
- 背景に敵は多いのに、攻撃するのは1〜2体だけ。
- 「密集したパルス」とだけ書き、発射源、波、重なりを定義しない。
- 衝突が押し合いになり、飛行が走行になる。
- 新しいマント付き資料に変更したのに「マントなし」の旧制約が残る。
- 反射、屈折、巨大さに幾何関係がなく、飾りになる。
- 全フレームを抽出しただけで、すべて確認したと報告する。

これらを診断と判断の方法に整理し、特定作品の数値や筋書きを万能テンプレートにはしません。敵やパルスの定量化で改善したというユーザー報告はありますが、統制実験やモデル横断の成功率検証ではありません。

## 定量化の例

> 制作上の目標：左右に発射源を3基ずつ配置。各発射源は1回につき1発、合計6発。第2波は第1波の0.4秒後に開始し、各パルスは0.6秒間画面内に残る。2波が重なる間に主人公が横移動し、外れたパルスは背後の路面に着弾する。

発射源、数量、時間関係を分けて指定しています。万能な最適値でも公式 API でもありません。分析では実測、推定、目標を区別し、遮蔽があれば範囲や下限を示します。

## 範囲と依存関係

- 文書を読むだけなら FFmpeg は不要です。メタデータ確認と抽出には FFmpeg/ffprobe、候補カット検出には任意で PySceneDetect を使えます。利用できない場合は確認範囲を明示します。
- 通常速度の視聴、連続フレーム確認、音声確認は別の作業です。聞いていない音を確認済みとしません。
- 生成の実行、素材のアップロード、非公開ファイルの公開は自動では行いません。現在の依頼での許可が必要です。
- プロンプトはフレーム単位の実行を保証しません。部分修正、分割生成、編集は選択肢であり、必須条件ではありません。
- 公開するのは独自に整理した文書のみで、私的な動画、キャラクター画像、会話ログ、第三者の映像フレームは含みません。
